# 场景推荐指南

## 生日蛋糕推荐

### 儿童生日（1-12岁）
**推荐款式**：
- 芒果慕斯（色彩鲜艳，清爽不腻）
- 草莓之恋（水果装饰，孩子喜欢）
- 红丝绒蛋糕（颜值高，拍照好看）

**推荐尺寸**：
- 6寸：适合4-6个小朋友
- 8寸：适合8-12个小朋友

**搭配建议**：
- +25元：卡通造型装饰
- +15元：彩色蜡烛套装
- +20元：水果拼盘装饰

**注意事项**：
- 避免含酒精款式（如提拉米苏、黑森林）

- 可要求减少甜度

### 糖尿病患者
**推荐款式**：
- 可定制无糖版本（需提前3天预订）
- 建议选择水果类蛋糕

**建议**：
- 需提前沟通无糖需求
- 价格可能增加20%
- 口感会有所不同

## 尺寸选择指南

### 6寸蛋糕
- **直径**：约15厘米
- **适用人数**：2-4人
- **适用场景**：
  - 小型聚会
  - 两人世界
  - 品尝试吃
  - 拍照道具

### 8寸蛋糕
- **直径**：约20厘米
- **适用人数**：4-6人
- **适用场景**：
  - 家庭聚会
  - 朋友聚会
  - 生日派对
  - 节日庆祝

### 10寸蛋糕
- **直径**：约25厘米
- **适用人数**：6-8人
- **适用场景**：
  - 大型聚会
  - 公司庆典
  - 婚礼
  - 大型活动

### 选择建议
- **人数较少**：选择6寸，避免浪费
- **人数较多**：选择8寸或10寸
- **不确定**：选择8寸，最通用
- **拍照为主**：选择6寸，精致好看
